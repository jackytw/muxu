Core Values

為什麼企業選擇「易派遣」？

告別通訊軟體雜亂交接與手動拼貼報表的痛點，以標準化流程建立可追溯、可稽核的現場管理體系。

工單集中管理

同一案件串起負責人員、施作進度、現場紀錄與佐證照片。現場人員與辦公室團隊資訊完全同步，查詢、派工與交接一清二楚。

報表格式一致

主管可依企業既有 Word 範本輸出可編輯文件與防竄改 PDF。系統自動將現場多張照片以每列兩張的美觀格式雙欄排列，免除手動剪貼耗時。

系統配合流程

不強迫企業改變既有習慣。工單表單欄位、狀態流轉、審核機制、外部系統介接（ERP/CRM/API）皆可依您的業務需求客製擴充。

部署方式彈性

可依資安要求規劃地端自有機房或雲端獨立隔離部署。專屬應用與資料庫邊界，大幅降低共用雲端環境誤設或漏洞所引發的連帶波及風險。

Target Teams

專業作業團隊設計

易派遣特別適合已有固定工單或報表格式，且希望自行掌握資料與部署環境的企業團隊。從指派、抵達到完工報告，一條龍無縫接軌。

建議的第一步

您只需提供一份現行使用的工單或報表樣本（Word / Excel / PDF），我們即可安排具體流程展示與部署需求評估訪談。

工程派工與施作

弱電工程、水電消防、裝修施工、空調工程等需要即時掌握現場師傅動態與施作前後對比的工程團隊。

設備維護與定檢

電梯機電、工廠產線機台、機房基礎設施、發電機維護等需嚴謹勾稽保養項目並拍照存證的技術團隊。

案場巡檢與稽核

物業管理巡檢、工安環保檢查、戶外站點巡邏、資產清點，需留下精準時間、紀錄與多角度影像佐證。

售後維修與到府服務

原廠售後維修、設備保固查驗、故障排除服務，需要直接產出正式完工維修單供業主或客戶留存。

System Capabilities

系統完整功能架構

提供直覺且嚴密的作業體驗，現場人員操作輕便，主管與管理員掌控全局。

1

工單與現場作業

  • 工單即時管理：查詢、篩選、新增與編輯，維護案場、狀態、日期、數量及費用。
  • 案件人員指派：明確指派及調派人員，清楚掌握每筆工單的負責對象。
  • 現場作業紀錄：新增、修改現場紀錄，支援歷程交接與報表自動彙總。
  • 多圖照片佐證：支援多圖批次上傳、預覽、原圖檢視、個別照片說明，支援 JPG、PNG、WebP。
桌機與手機瀏覽器皆可完美操作
2

主管報表與範本

  • Word / PDF 一鍵輸出：系統自動將案件資料（業主、案場、日期、負責人員）自動套版。
  • 照片雙欄美觀排列：現場上傳照片以每列兩張規則自動編排至正式報表，無需人工調整排版。
  • 自訂範本管理：Admin 可自由下載目前範本調整抬頭、Logo、字型與位置，上傳即可即時生效。
  • 上傳檢驗機制：範本更換時自動檢查必要標記結構，確保產製穩定，支援一鍵還原預設。
保留企業既有官方識別與排版格式
3

角色權限與防護

  • 後端嚴格權限：Admin（管理員）、Supervisor（主管）、User（現場人員），每次請求重新向資料庫校驗。
  • 報表存取保護：報表檢視與匯出 API 僅對主管角色開放，Admin 不自動濫權取得，角色降權即刻阻斷。
  • 內建應用防護：全面支援 CSRF 防護、樂觀鎖版本覆寫衝突檢查、照片上傳格式驗證與刪除確認。
  • 完整系統日誌：每日記錄權限阻斷、報表匯出與範本更換等重要事件，備查與稽核皆有憑有據。
符合企業資安治理與責任邊界
Deployment Architecture

地端部署 vs. 雲端獨立部署

企業可依資料治理政策、網路架構與維運能力，自由選擇最適切的部署模式。

比較維度 地端私有部署 (On-Premises) 雲端獨立部署 (Dedicated Cloud)
運作位置 企業自有機房或指定實體主機環境 企業自有或約定專屬雲端資源邊界
資料位置 完全留在企業指定內部伺服器，資料落地保障 存於約定雲端區域及專屬資料庫與儲存服務
網路存取方式 可規劃純內網、企業 VPN 或受控對外反向代理 可規劃專屬私有網路 (VPC)、VPN 與受控入口
管理與維運責任 企業 IT 維運或委託沐旭科技維護，責任依約明確約定 企業與沐旭服務團隊依分工矩陣共同管理
適合需求情境 內網使用 法規資料落地 自備機房 跨據點多案場 獨立隔離環境 彈性擴充
安全防禦優勢 隔絕外網直接曝險，完全由內網政策控制 獨立應用與獨立資料庫，杜絕多租戶共用環境之誤設與連帶入侵風險
關於獨立部署架構之安全說明： 當企業與其他客戶共用同一應用或資料庫時，隔離設計若出現瑕疵可能擴大影響。易派遣獨立部署方案規劃專屬應用邊界、獨立資料庫與圖檔儲存權限，大幅降低此類連帶相依。各項資源隔離範圍均明確載明於提案與驗收文件。

FAQ

常見問題解答

關於易派遣的功能、客製化與部署模式之常見疑問。

1. 易派遣支援哪些作業系統與裝置？現場師傅需要安裝 App 嗎？

不需要強制安裝額外 App！易派遣採用響應式 Web 介面，現場人員使用 iOS / Android 手機或平板瀏覽器即可直接登入、回報紀錄與上傳照片；辦公室主管與管理員則使用電腦瀏覽器進行工單審核與報表產出。

2. 主管匯出的報表能否客製為我們公司既有的 Word / PDF 驗收格式？

可以！易派遣支援企業自訂範本。系統會將工單資料（業主、案場、日期、施作項目、人員）自動填入指定標記，並將現場照片以每列兩張規則自動雙欄排版。Admin 管理員可隨時下載範本調整抬頭、Logo、字型再上傳套用。

3. 「地端私有部署」與「雲端獨立部署」有何差異？如何選擇？

「地端私有部署」將系統完全架設於企業自有機房或內網，適合對資料落地、法規合規有嚴格要求的企業；「雲端獨立部署」則為企業開闢專屬獨立的雲端應用與資料庫邊界，隔絕外部多租戶共用環境的連帶資安風險，並享有跨區彈性擴充優勢。

4. 能否介接企業現有的 ERP、CRM 或外部身分認證 (SSO)？

可以。沐旭科技團隊擁有深厚系統整合顧問經驗，可依專案需求客製工單欄位、審批流程、API 介接、既有資料庫歷史轉移、以及企業級 SSO / MFA 雙因子身分驗證整合。

5. 如何開始第一步評估？需要準備什麼資料？

您只需提供一份現行使用的工單或驗收報表樣本（Word、Excel 或 PDF），沐旭科技顧問即可為您安排一場針對該情境的現場作業與報表匯出實機展示，並評估最符合預算的部署方案。
